# Datenschutzerklärung – The next Studio Tag Bot

**Stand: 22. November 2026**

## 1. Welche Daten werden gespeichert?
Der Bot speichert folgende Informationen:

- Discord-Benutzer-IDs
- Zugeordnete Server-Tags
- Ursprüngliche Server-Nicknames, sofern für die Nickname-Verwaltung benötigt

## 2. Wofür werden die Daten verwendet?
Die Daten werden ausschließlich für die Funktionen des Tag-Systems verwendet:
- Tags vergeben und entfernen
- Nicknames automatisch anpassen
- Tag-Profile anzeigen

## 3. Speicherung
Die Daten werden in lokalen JSON-Dateien auf dem Server gespeichert, auf dem der Bot betrieben wird.

## 4. Weitergabe
Die gespeicherten Daten werden nicht verkauft. Eine Weitergabe erfolgt nur, soweit dies für den Betrieb erforderlich oder gesetzlich vorgeschrieben ist.

## 5. Löschung
Gespeicherte Daten können im Rahmen der geltenden Datenschutzvorschriften gelöscht werden.
